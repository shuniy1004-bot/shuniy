# SHUNI OFFICIAL

이예다 사이트의 레이아웃 골격(잡지형 챕터 표제 + 유리 카드 + 2단 그리드)을 상속하고,
색·세계관·연출을 슈니의 별 / 밤하늘로 바꾼 전체 사이트입니다.

- 라이트 = 맑은 낮 하늘 (기본) · 다크 = 밤하늘 우주, `localStorage('theme')` 로 전 페이지 공용
- 팬 캐릭터(슈몽)가 배경을 떠다니고, 클릭하면 튕기면서 말풍선이 뜹니다.
  글자를 가리지 않도록 **유리 카드 뒤로** 흐르고, 카드 사이 틈과 양옆 여백에서 눌립니다.
  캐릭터 이미지를 넣기 전에는 별 스프라이트로 대체됩니다
- 폰 브라우저에서도 PC 배치로 뜨고, 숲 앱에서는 `PC 화면 ↗` 버튼으로 넘어갑니다

## 파일

```
index.html            메인 (대시보드)
profile/              프로필
notice/  schedule/  song/  dress/  work/  diary/     카테고리 6종
game/                 미니게임 — 사다리 · 구슬 레이스 · 룰렛
admin/                관리자
overlay/              OBS "지금 트는 노래"
css/cosmos.css        전 페이지 공통 테마
js/cosmos.js          전 페이지 공통 동작
pcview.js             ?pc=1 일 때 인앱 브라우저에서 PC 배치
supabase.js           DB 연동 — 키 입력 완료
supabase_setup.sql    표 13개 + 접근 권한(RLS)
assets/               슈니 사진 4장 + 배경
```

사진은 원본 3840×2160 · 6~8MB 를 1600px · 90KB 안팎으로 줄였습니다.
배경은 PIL 로 미리 블러해서 8.8KB 입니다 (CSS 필터를 쓰면 배경이 body 뒤로 숨습니다).

## 남은 셋업 — 순서를 지켜야 합니다

Supabase 프로젝트(`gjjtwoigivdrbfweymkd`)와 `supabase.js` 키 입력은 끝났습니다.

1. **Authentication → Users → Add user** 로 관리자 계정 생성 (Auto Confirm User 켜기)
2. SQL Editor 에 `supabase_setup.sql` 전체를 붙여넣고 Run
   — 1번을 먼저 하지 않으면 쓰기 권한이 `authenticated` 로 잠겨 본인도 저장할 수 없습니다
3. GitHub 업로드 → Cloudflare Pages 연결 (Framework = None, 빌드 설정 비움)
4. 재배포 후 Ctrl+Shift+R
5. `배포주소/admin/` 으로 들어가 1번에서 만든 계정으로 로그인

SQL 을 돌리기 전까지 페이지는 기본값으로만 뜹니다 (에러 없이 정상 동작).

## 관리자

탭은 **값이 어느 화면에 나오는지** 기준으로 갈랐고, 카드마다 "나오는 곳" 을 한 줄로 적었습니다.

| 탭 | 들어 있는 것 |
|---|---|
| 🏠 메인 | 메인 사진, 방송 요일, 관련 링크, 팬 캐릭터 |
| 🎀 프로필 | 프사·이름, 프로필 큰 사진, 프로필 정보, 한마디·소개, 태그/좋아싫어, 능력치·목표·컨텐츠, 노래 정보, 다시보기 |
| 📢📅🎵👗📖📓 | 각 카테고리 데이터 |
| ✉ 문의 | 사이트에서 들어온 문의 (관리자만 열람) |
| ✏️ 문구 | 화면 고정 문구 77개 — 검색칸으로 찾습니다 |
| 🎨 테마 | 팔레트 8색 (프리셋 5종 + 대비 진단) · 글자 크기 4단 배율 |

- 상단에 **백업 받기 / 백업 복원(.json)**, 저장 안 한 변경이 있으면 빨간 점과 이탈 경고
- 로그인은 Supabase Auth 입니다. 코드에 비밀번호가 없고, 계정은 Supabase 대시보드에서 관리합니다
- 상단 **자가진단** 줄이 저장 키 · 문구 · 팔레트가 다 연결되어 있는지 매번 확인합니다

### 값 형식

- 능력치 — 한 줄에 `이름:숫자` (0~100 밖은 잘립니다)
- 목표 — 한 줄에 `상태|내용`. 상태에 완료·달성이 들어가면 채워진 배지
- 컨텐츠 — 한 줄에 `날짜|제목|주소`
- 방송 요일 — 7줄, **첫 줄이 월요일**. 비우거나 `휴방` 이라고 쓰면 휴방
- 나머지 목록(키워드·성격·좋아·싫어·TMI·말풍선) — 한 줄에 하나

## 미니게임

- **사다리타기** — 가로줄을 그리지 않고 내려가는 선만 드러나는 방식. 2~10명

  `build/shell.py` 한 곳에서 나오므로 페이지마다 어긋날 수 없습니다

## 글자 크기

라벨 층이 9~12px 로 너무 작다는 지적을 받고 층 전체를 다시 잡았습니다.
